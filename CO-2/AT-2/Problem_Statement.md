## Objective

To analyze real-world cloud computing scenarios and design suitable cloud architectures that address scalability, performance, security, reliability, disaster recovery, and cost optimization using virtualization and cloud-native technologies.

## Assessment Questions

1. **Scalable Video Streaming:** Design a cloud architecture for a media company that must support millions of concurrent users with minimal buffering. Explain caching, load balancing, auto-scaling, and cost optimization.

2. **Container Orchestration and Multi-Cloud:** Propose a solution for a fintech startup deploying containers across multiple cloud providers. Explain orchestration, deployment consistency, service discovery, scaling, and the benefits and risks of multi-cloud deployment.

3. **Backup and Disaster Recovery:** Design a cloud-native backup and disaster recovery strategy for an e-learning platform that has experienced accidental data deletion. Explain backup, replication, versioning, Recovery Time Objective (RTO), Recovery Point Objective (RPO), and business continuity.

4. **Secure Hybrid Cloud:** Design a secure hybrid cloud architecture for a government agency that must keep sensitive applications on-premises while using public cloud services for non-sensitive workloads. Explain secure communication, identity management, encryption, and hybrid-cloud management challenges.

5. **Multi-Region High Availability:** Propose a multi-region deployment strategy for a SaaS provider that must continue operating if one cloud region fails. Explain data replication, failover, monitoring, alerting, and fault tolerance.

## Expected Outcome

To demonstrate the ability to apply cloud computing and virtualization concepts to practical scenarios, justify architectural decisions, identify technical risks, and recommend suitable measures for performance, security, availability, and cost efficiency.
