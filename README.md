# 🌐 What This Repository Contains

This repository contains the complete practical work performed as part of the **CSA15 – Cloud Computing and Big Data Analytics** laboratory.

The repository covers:

<div align="center">

| ☁️ Cloud | 🖥️ Virtualization | 🗄️ Data | ⚡ Big Data |
|---|---|---|---|
| SaaS | Virtual Machines | Cloud Storage | Hadoop |
| PaaS | VirtualBox | Cloud Database | MapReduce |
| IaaS | VMware | SQL | NameNode |
| Azure | VM Cloning | DaaS | DataNode |
