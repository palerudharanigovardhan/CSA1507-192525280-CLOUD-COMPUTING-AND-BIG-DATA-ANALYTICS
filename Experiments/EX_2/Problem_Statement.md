## Problem Statement

To develop a cloud-based **Property Buying & Rental System** using **Zoho One / Zoho Creator** to manage property buying and rental information in Chennai. The system should allow users to enter and manage details such as **customer name, phone, email, transaction type, property type, area, location, property value, rental value, rental agreement, and property status**. The system should store the submitted property details in the cloud and provide an easy-to-use interface for managing property records, thereby demonstrating **Software as a Service (SaaS)**.
