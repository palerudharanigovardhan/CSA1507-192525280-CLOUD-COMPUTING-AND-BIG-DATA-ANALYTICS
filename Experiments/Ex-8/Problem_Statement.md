# Experiment 8: Student Counselling System Using Zoho One (SaaS)

## Problem Statement

To develop a cloud-based Student Counselling System using Zoho One / Zoho Creator to record, store, and manage student counselling details. The system should maintain student name, registration number, department, year of study, counselling date, counsellor name, counselling type, reason for counselling, follow-up requirement, and remarks. It should allow authorized users to submit, view, and manage counselling records through a cloud-based application, demonstrating the Software as a Service (SaaS) model.
