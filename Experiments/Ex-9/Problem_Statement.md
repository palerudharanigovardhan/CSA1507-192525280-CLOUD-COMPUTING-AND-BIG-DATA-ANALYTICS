# Experiment 9: Hospital Information System Using Zoho One (SaaS)

## Problem Statement

To develop a cloud-based Hospital Information System using Zoho One / Zoho Creator to record, store, and manage patient information and appointment details. The system should maintain patient name, patient ID, age, gender, phone number, address, doctor name, department, appointment date, appointment time, and appointment status. It should allow authorized hospital staff to submit, view, and manage patient records through a cloud-based application, demonstrating the Software as a Service (SaaS) model.
