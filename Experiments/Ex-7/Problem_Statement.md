# Experiment 7: Students Attendance System Using Zoho One (SaaS)

## Problem Statement

To develop a cloud-based Students Attendance System using Zoho One / Zoho Creator to record, store, and manage student attendance details. The system should maintain student name, registration number, department, year of study, date, subject, attendance status, and remarks. It should allow attendance records to be submitted, viewed, and managed through a cloud-based application, demonstrating the Software as a Service (SaaS) model.
