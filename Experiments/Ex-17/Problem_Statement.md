# Problem Statement

To change the **hardware compatibility of an existing virtual machine** using virtualization software such as **VMware Workstation** and execute basic Unix commands to verify its operation. The experiment involves selecting or cloning a virtual machine, configuring a supported hardware compatibility version, and running commands such as `pwd`, `ls`, `whoami`, `date`, `uname -a`, and `df -h` in the guest operating system. This demonstrates virtual machine hardware compatibility management and the execution of Unix commands in a virtualized environment.
