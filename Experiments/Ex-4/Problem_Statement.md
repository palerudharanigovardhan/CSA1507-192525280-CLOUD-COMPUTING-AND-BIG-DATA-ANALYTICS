# Experiment 4: Library Book Reservation System Using Zoho One (SaaS)

## Problem Statement

To develop a cloud-based Library Book Reservation System for SIMATS Library using Zoho Creator to store, manage, and view book details, including book title, author, publication, year of publication, edition, number of copies, rack number, and book status. The system should allow library staff to maintain book records and track whether books are Available, Taken, or Returned using a Software as a Service (SaaS) platform.
